# Skills

Vendored from https://github.com/emilkowalski/skills at commit
`2d228630ba1446365f614a108cb8252f1feda202`, MIT licensed (see `LICENSE-emilkowalski`).

Picked for LightRays because the game lives or dies on feel:

- `emil-design-eng`: UI polish, component and motion principles.
- `animate`: building a new animation step by step.
- `apple-design`: gesture-driven, physical, interruptible interactions (the rotation dial).
- `animation-performance`: keeping the render loop and DOM overlays inside the frame budget.
- `review-animations`: strict review of motion code (invoke explicitly).
- `find-animation-opportunities`: read-only scan for places that should animate.

Left out: React Native/Expo, Swift, Sonner and mobile-native skills, which don't apply to a
three.js web game.
